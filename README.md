# DailyDo - 每日待办

一款基于 Tauri 构建的现代化桌面待办事项管理应用。轻量、快速、功能强大，支持周期任务、看板视图、数据分析、附件管理等丰富功能。

---

## ✨ 功能特性

### 📋 核心待办管理
- 创建待办事项，支持标题、富文本备注、优先级（高/中/低）、截止日期
- 三态切换：待处理 → 进行中 → 已完成
- 快速添加（行内输入）和完整添加（弹窗表单）两种模式
- 双击待办卡片查看详细详情
- 软删除机制，7天自动清理回收站

### 🔄 周期任务
- 支持五种周期类型：每日、工作日、每周、每月、每年
- 工作日周期智能识别自定义日历（跳过休息日）
- 周期组管理：统一启用/禁用/编辑/删除
- 完成当前实例自动生成下一期，继承标签和步骤

### 📅 日历视图
- 月历网格展示，直观查看每日任务完成情况
- 颜色编码：绿色（全部完成）、琥珀色（部分完成）、蓝色（工作日无任务）、红色（逾期）
- 自定义工作日/休息日管理
- 点击日期查看当日待办详情

### 📊 数据分析
- 多维度统计：今日完成、本周完成、待处理数、连续打卡天数
- 标签分布饼图、优先级分布饼图
- 每日任务数量柱状图、完成率趋势折线图
- 支持 7天/30天/90天 时间范围筛选

### 🏷️ 标签系统
- 彩色标签管理，支持自定义颜色
- 10个预设标签（会议、代码审查、Bug修复、功能开发等）
- 多对多关联，一个待办可打多个标签

### ✅ 子任务步骤
- 每个待办可添加有序步骤（子任务）
- 步骤全部完成时自动标记父任务为"已完成"
- 周期任务复制时自动复制步骤（重置为未完成）

### 📎 附件管理
- 为待办添加文件附件（存储在应用数据目录）
- 独立附件管理页面：查看、打开、定位、删除
- 批量清理已完成待办的附件，释放存储空间

### 📝 模板系统
- 创建可复用的待办模板（标题、优先级、周期、标签、步骤）
- 快速从模板生成新待办

### 🗂️ 看板视图
- 三列看板布局（待处理/进行中/已完成）
- 拖拽切换状态，支持列折叠
- 历史未完成任务按日期分组展示

### 🎨 主题与个性化
- 明暗主题切换
- 自定义背景图片（支持 JPG/PNG/WebP）
- 可配置侧边栏模块（显示/隐藏/排序）

### 💾 数据导入导出
- JSON 完整备份与恢复
- Markdown 格式化导出（按日期分组，含状态图标）
- Excel (.xlsx) 表格导出
- 支持日期范围筛选导出

### 🗑️ 回收站
- 软删除保护，误删可恢复
- 7天自动过期清理
- 支持永久删除和批量清空

### 🔔 提醒功能
- 为待办设置提醒时间
- 到期自动提示

### 🪟 迷你模式
- 紧凑悬浮窗（400x540px），固定右下角
- 始终置顶，快速查看和操作
- 一键切换到完整模式

| 技术 | 说明 |

| **ECharts** | 数据可视化图表 |
| **Quill** | 富文本编辑器 |

## 📦 安装与构建

### 环境要求
- Node.js 16+
- Rust (cargo)
- Tauri CLI

### 开发模式
```bash
# 安装依赖
npm install

# 启动开发服务器
npm run tauri dev
```

### 构建生产版本
```bash
# 构建桌面应用
npm run tauri build
```

构建产物位于 `src-tauri/target/release/bundle/`：
- `msi/` - Windows MSI 安装包
- `nsis/` - Windows NSIS 安装包（.exe）

## 📁 项目结构

```
dailydo/
├── src/                    # Vue 前端
│   ├── components/         # 组件
│   ├── views/              # 页面视图
│   ├── stores/             # Pinia 状态管理
│   ├── utils/              # 工具函数（db.js 等）
│   └── App.vue             # 根组件
├── src-tauri/              # Tauri/Rust 后端
│   ├── src/
│   │   ├── main.rs         # 入口，注册命令
│   │   ├── db.rs           # 数据库初始化与表结构
│   │   └── commands.rs     # Tauri 命令（CRUD 操作）
│   └── Cargo.toml          # Rust 依赖
└── docs/                   # 文档与资源
```
